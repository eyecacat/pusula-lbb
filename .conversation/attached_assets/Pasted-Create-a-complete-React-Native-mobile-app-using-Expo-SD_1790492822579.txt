Create a complete React Native mobile app using Expo SDK 51 (managed workflow) 
for a health emergency wearable system called "Life Black Box".
The app communicates with a Deneyap Kart 1A (ESP32-S3) over BLE using the 
Nordic UART Service UUID: 6E400001-B5A3-F393-E0A9-E50E24DCCA9E.

────────────────────────────────────────────
BLE PROTOCOL
────────────────────────────────────────────

Device name to scan for: "LifeBlackBox"
Service UUID:    6E400001-B5A3-F393-E0A9-E50E24DCCA9E
Notify UUID:     6E400003-B5A3-F393-E0A9-E50E24DCCA9E  (device → app)
Write UUID:      6E400002-B5A3-F393-E0A9-E50E24DCCA9E  (app → device)

Incoming JSON from device (parse every 1 second):
{
  "hr": 72,       // heart rate bpm (int)
  "spo2": 98,     // SpO2 % (int)
  "acc": 1.02,    // total acceleration in g (float)
  "temp": 36.5,   // ambient temperature °C (float)
  "hum": 45,      // humidity % (int)
  "co": 120,      // CO sensor raw ADC value (int)
  "fall": false,  // fall detected bool
  "state": 0      // 0=NORMAL, 1=CONFIRM_WAIT, 2=ALERT_SENT
}

Special incoming packet for emergency:
{ "ALARM": "ACIL_SOS" }

Outgoing command to cancel alert:
Write single byte 'C' to Write characteristic

────────────────────────────────────────────
EMERGENCY FLOW (emergency.tsx — full screen modal)
────────────────────────────────────────────

Triggered when:
  a) device sends { "ALARM": "ACIL_SOS" } packet
  b) state field becomes 1 (CONFIRM_WAIT) → show countdown
  c) user taps SOS button manually

Screen layout:
- Dark red background, white text
- Top: large animated warning icon (pulsing red triangle ⚠️)
- Title: "ACİL DURUM ALGILANDI"
- Detected reason (e.g. "Düşme Algılandı + Düşük SpO2 Tespit Edildi")
- EmergencyCountdown ring: 10-second animated circular countdown
  → while counting: phone vibrates every 2 seconds, plays alert sound
- Two large buttons:
    [✓ Ben İyiyim — İptal Et]   → writes 'C' to BLE, dismiss screen
    [🆘 Yardım Çağır]           → skip countdown, trigger immediately
- If countdown reaches 0 OR user taps "Yardım Çağır":
    1. Send SMS to all emergency contacts (expo-sms):
       "ACİL: [userName] sağlık durumu kritik. Konum: [timestamp]. 
        Life Black Box sistemi otomatik alarm verdi. Lütfen hemen arayın."
    2. Show "Mesaj Gönderildi ✓" confirmation per contact
    3. Play audio: first-aid guidance based on detected event type
       - fall → "Düşme_ilkYardim.mp3" 
       - low HR / SpO2 → "Kardiyak_ilkYardim.mp3"
       - CO → "KarbonMonoksit_ilkYardim.mp3"
       (use placeholder audio or TTS if files not available)
    4. Log event to AsyncStorage with full sensor snapshot
    5. Show post-alert screen: event summary + "Ambulans Çağır" button 
       that opens tel:112

────────────────────────────────────────────
ERROR HANDLING & EDGE CASES
────────────────────────────────────────────

- BLE permission denied → show permission rationale screen 
  with step-by-step guide (Android: BLUETOOTH_SCAN + BLUETOOTH_CONNECT)
- BLE disconnected mid-session → auto-reconnect every 5 seconds, 
  show "Yeniden Bağlanıyor..." banner, do NOT trigger false alarm
- No emergency contacts → block SOS send, show "Acil kişi eklenmedi" 
  warning with direct link to Contacts screen
- Invalid/NaN sensor values → show "--" placeholder, skip anomaly check 
  for that reading only
- SMS unavailable (iPhone restrictions or no SIM) → show warning 
  + copy-to-clipboard fallback with pre-filled message
